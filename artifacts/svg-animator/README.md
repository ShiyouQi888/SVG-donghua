# SVG Animator — 关键帧时间轴编辑器

纯前端 SVG 动画制作工具，支持**可视化关键帧时间轴**编辑。用浏览器打开 `index.html` 即可使用。

## 核心：关键帧时间轴

底部时间轴面板提供类似专业动画软件的编辑体验：

| 操作 | 说明 |
|------|------|
| **展开图层** | 点击左侧图层名展开 5 条属性轨道 |
| **添加关键帧** | 属性轨道上**双击**，或右侧「关键帧」面板按钮 |
| **拖拽关键帧** | 拖动菱形标记调整时间 |
| **选中关键帧** | 单击菱形，右侧可改数值与时间 |
| **播放头** | 在标尺或轨道空白处拖动 scrub；左右方向键微调 |
| **缩放时间轴** | 工具栏「缩放」滑条调整 px/秒 |

### 可动画属性

- **透明度 (opacity)**
- **X / Y 位移**（相对基础位置的偏移）
- **旋转 (rotate)** 单位：度
- **缩放 (scale)**

属性之间在关键帧间做平滑插值（smoothstep）。

### 快捷预设

在「关键帧」面板一键写入整段关键帧：

- 淡入 / 淡出
- 放大入场
- 弹跳
- 右滑入
- 旋转一圈

## 其他功能

- 绘图：矩形、圆、椭圆、直线、文字；导入 SVG 拆层
- 属性面板：颜色、描边、尺寸、在当前时间点的变换值
- 播放 / 暂停 / 停止（空格键）
- 导出带 CSS `@keyframes` 的独立 SVG（无限循环）
- 画布缩放、背景切换

## 快捷键

| 按键 | 功能 |
|------|------|
| `V` | 选择工具 |
| `R` | 矩形 |
| `C` | 圆形 |
| `T` | 文字 |
| `Space` | 播放 / 暂停 |
| `←` / `→` | 播放头 −/+ 0.05s（Shift 为 0.5s） |
| `Delete` | 删除选中关键帧或图层 |

## 推荐工作流

1. 添加或导入形状
2. 选中图层，展开时间轴轨道
3. 把播放头移到 0s，添加起始关键帧（如 scale=0.2, opacity=0）
4. 移到 1s，改属性面板中的缩放/透明度（或双击轨道），形成结束关键帧
5. 播放预览 → 导出 SVG

## 技术说明

- 无依赖，单 HTML 文件
- 预览用 `requestAnimationFrame` 按关键帧插值
- 导出将所有时间点采样为 CSS `@keyframes` 百分比
- 全部在本地浏览器完成，不上传数据
