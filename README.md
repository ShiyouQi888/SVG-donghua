# 金帧 Kairo

金帧是一款运行在浏览器中的 SVG 动画编辑器。它把画布、图层、关键帧时间线、预览和导出工具放在同一个工作台里，适合制作标题动画、品牌片头、字幕、社交媒体动效和简单的矢量动画。

项目采用本地优先的工作方式：动画文档保存在当前浏览器，图片素材保存在浏览器的 IndexedDB 中，不需要账号或远端数据库即可开始编辑。

## 功能

### 画布与图层

- 使用矩形、圆形、椭圆、五角星、文字和钢笔工具创建图层。
- 选择图层后，可在画布上移动、旋转、缩放和编辑钢笔路径；拖动时支持 Shift 约束比例及中心缩放。
- 鼠标滚轮缩放画布，按住空格拖动画布；开启磁吸后可对齐到画布中心和其他图层。
- 可切换安全框，预览常用的动作安全区和标题安全区。
- 双击文字图层可直接编辑文本。导入的图片和 SVG 素材可拖到画布，或添加为图层。
- 图层支持显示/隐藏、重命名、层级前后调整、撤销和重做。

### 关键帧与动画

- 时间线提供透明度、合并显示的 XY 位置、旋转、缩放、填充颜色、描边颜色和描边粗细属性轨道。
- 支持自动 K 帧、逐帧微调、关键帧多选、框选移动、复制和粘贴。
- 关键帧可使用线性、缓入缓出、定格或贝塞尔插值；位置关键帧可以编辑空间贝塞尔路径和控制手柄。
- 时间读数显示时:分:秒:帧；标尺会随缩放调整主刻度和帧刻度，播放头和关键帧以项目帧率对齐。
- 矩形圆角、文字字体、字号和字重等图层属性可在右侧属性面板按图层类型设置。
- 时间线可设置循环播放，也可关闭循环后播放一次。
- 可开启运动模糊并调节强度；预览和导出会根据图层的动画运动计算模糊。

### 模板预设

右侧模板面板内置可组合、可反复添加的图层与动画预设，模板可以搜索并按类别筛选。常用图层预设包括：

- **文字与标题：**主标题、章节标题、副标题、眉题、下三分之一标题和字幕行。
- **图形与版式：**胶囊标签、行动按钮、信息卡片、全屏背景、椭圆光环、星形徽章和分隔线。
- **动画：**淡入上浮、柔和淡入、横向滑入、弹性弹入、旋转落位、循环呼吸、摆动强调和颜色变化。

选中图层后可以把图层外观保存成自己的模板，供之后复用。自定义模板保存在当前浏览器的本地存储中。

### 画布尺寸与导出

- 项目画布和导出尺寸可以分别设置。项目尺寸提供横版 Full HD、横版 HD、竖版 9:16、正方形 1:1、人像 4:5 和经典 4:3 等预设。
- 支持导出 SVG 动画、查看并复制 SVG 源码、导出当前播放头的 PNG、导出 WebM 视频和 GIF 动图。
- SVG、PNG 和 GIF 支持透明背景。WebM 的透明度取决于当前浏览器的编码器支持情况。
- GIF 以 12 fps 编码；PNG 导出当前时间点的画面；SVG 动画以 CSS 关键帧输出并重复播放。时间线循环开关控制编辑器预览的播放方式。

## 快速开始

要求 Node.js 22 和 npm。

```bash
npm install
npm run dev
```

开发服务器默认监听 `http://localhost:8080`。启动脚本会通过项目的环境包装器加载预览所需配置。

## 常用命令

```bash
npm run dev        # 启动开发服务器
npm run typecheck  # TypeScript 类型检查
npm run build      # 构建生产版本
npm run preview    # 预览生产构建
npm test           # 运行项目测试
npm run lint       # ESLint 检查
```

构建命令完成 Vite/Nitro 生产构建后会执行数据库迁移脚本；未设置 `DATABASE_URL` 时，迁移脚本会跳过远端数据库迁移。

## 编辑器操作

| 操作 | 说明 |
| --- | --- |
| 选择工具 + 拖动 | 选择和移动图层 |
| 拖动角点/边缘手柄 | 缩放图层 |
| Shift + 拖动缩放手柄 | 从图层中心按比例缩放 |
| Shift + 拖动画布绘制图形 | 按比例绘制；圆形工具始终绘制正圆 |
| 双击文字 | 编辑画布上的文字 |
| 滚轮 | 缩放预览画布 |
| 空格 + 拖动 | 平移预览画布 |
| 拖动时间线播放头 | 预览指定时间 |
| 时间线框选 | 多选关键帧；拖动可整体移动 |
| 右键关键帧 | 打开插值与贝塞尔相关菜单 |
| `Ctrl/⌘ + Z` | 撤销 |
| `Ctrl/⌘ + Shift + Z` 或 `Ctrl/⌘ + Y` | 重做 |
| `Space` | 播放/暂停；焦点在文字或输入框时不会触发 |
| `J` / `K` | `J` 向后、`K` 向前逐帧移动播放头 |
| `Shift + K` | 为选中图层的已启用属性添加关键帧 |
| `F` | 对选中的关键帧应用缓入缓出 |
| `V` | 切换到选择工具 |
| `Delete` / `Backspace` | 删除选中的关键帧或图层 |

快捷键在输入框、下拉菜单或文字编辑状态下会让位给当前输入操作。

## 数据保存

- 当前动画文档保存在浏览器 `localStorage`，包括图层、关键帧、画布尺寸、导出尺寸和循环等设置。
- 项目素材库保存在浏览器 IndexedDB 中，支持图片与 SVG 文件。
- 自定义图层模板保存在浏览器 `localStorage` 中。
- 更换浏览器或清理站点数据不会自动同步这些本地内容；需要长期归档时，请保存导出的 SVG 或媒体文件。

## 技术栈

| 部分 | 技术 |
| --- | --- |
| 应用界面 | React 19、TypeScript |
| 路由与应用框架 | TanStack Start、TanStack Router |
| 构建与开发 | Vite 8、Nitro（Vercel preset） |
| 样式 | Tailwind CSS 4 |
| 编辑器状态 | Zustand 5 |
| 画布与矢量输出 | 原生 SVG、CSS Keyframes |
| 图标 | Lucide React |
| 项目素材存储 | IndexedDB |
| 动画导出 | SVG/CSS、Canvas、MediaRecorder、gifenc |

## 项目结构

```text
src/
├── components/animator/
│   ├── Editor.tsx          # 编辑器布局、工具栏、导入与播放调度
│   ├── Stage.tsx           # SVG 预览画布、绘制、选择与手柄交互
│   ├── Timeline.tsx        # 关键帧时间线、属性轨道与播放设置
│   ├── Inspector.tsx       # 当前图层的上下文属性
│   ├── TemplatePanel.tsx   # 图层模板、动画预设与自定义模板
│   ├── RightPanel.tsx      # 右侧属性/模板面板及窄屏面板
│   ├── ProjectPanel.tsx    # 图片与 SVG 项目素材栏
│   └── ExportDialog.tsx    # SVG、源码、PNG、WebM 与 GIF 导出
├── lib/animator/
│   ├── model.ts            # 图层模型、插值、时间采样与 SVG 构建
│   ├── store.ts            # Zustand 文档状态、持久化和撤销/重做
│   ├── templates.ts        # 内置图层和动画模板定义
│   ├── media-export.ts     # PNG、WebM 和 GIF 渲染导出
│   └── project-assets.ts   # IndexedDB 素材读写
├── routes/                 # TanStack Start 路由
└── styles.css              # Tailwind 主题与画布样式
```

## 部署

生产构建由 Vite 与 Nitro 生成，项目已配置 Vercel preset。将仓库导入 Vercel 后使用默认构建脚本即可生成部署产物。编辑器本身的文档、模板和素材数据保存在用户浏览器，因此部署应用不需要为这些编辑内容配置数据库。
